# Personal AI Assistant (Jarvis)

A desktop AI assistant built using Python that can execute voice commands, open applications, and automate Windows tasks.

## Features

- Voice Recognition
- Text to Speech
- Open Applications (Chrome, YouTube, etc.)
- Shutdown Confirmation (Yes/No)
- Time-based Commands
- AI Response Integration
- Windows Automation (win32com)

## Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- win32com (pywin32)
- datetime
- webbrowser
